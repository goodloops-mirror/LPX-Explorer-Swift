LPX Explorer

Quick guide · find tracks, plug-ins and bounces across your Logic Pro projects – without opening Logic.

Getting started

  1. Add a folder that contains your .logicx projects (File ▸ Add Folder… ⌘O, or drop a folder on the window). Subfolders and Backups folders are included.
  2. The first scan reads every project once. After that only new or changed projects are read again, so starting the app is fast. ⌘R rescans.
  3. The app is read-only: it never changes a project, never opens Logic and makes no network requests. Everything it remembers is kept in ~/Library/Application Support/LpxExplorer.

The window

From left to right: folders (and the Plug-ins view) · the project list · the project's details with its bounces below · the tracks in Logic's order, hidden tracks marked. The Tracks button in the toolbar hides or shows the track pane (View ▸ Reset Column Widths restores the default layout). Click a key or tempo in the details to find similar projects. Right-click a project to reveal it in Finder or copy its path.

Searching

  • The search box (top right) matches everything: project names, track and object names, channel names and plug-ins. Several words must all match.
  • The three fields above the list match only their own field – Project name, Track / object name, Plug-in – and narrow the results further. Buttons below them limit the result to audio, instrument or folder tracks, to projects with or without a bounce, and show or skip hidden tracks.
  • Results are the matching projects, each followed by the tracks inside it that matched. Click a track to open its project and jump to that track. Searching covers the whole library, not only the selected folder.

Bounces and the player

  • A bounce belongs to a project when its file name starts with the project's name, version number included; whatever follows is ignored. A file with STM#nn after the name is stem nn; everything else is a mix, the newest being the main one.
  • They are looked up in Bounces folders in the project's folder and in every folder above it up to the library folder (so projects in Backups find the Bounces next to it), including all subfolders, and inside the project package.
  • Click a bounce to play it in the player at the bottom: click or drag the waveform to jump, Space plays or pauses (except while you type), and “back to project” returns to where it started. It keeps playing while you browse.

Plug-ins and compatibility

The Plug-ins view lists every plug-in used in the library with the projects that use it. A project that needs plug-ins this Mac doesn't have shows a warning; “Missing plug-ins only” filters for them. Plug-in names come from the installed Audio Units (auval).

Good to know

  • Track names are shown exactly as stored; names are never used to guess what a track is.
  • Projects from older Logic versions are read too (tested with Logic Pro X 10.5 and 11).
  • Reveal in Finder is the only way a project is “opened” – never launched in Logic.
